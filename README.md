
## 🛠️ Getting Started

# En-Tech S.C Full-Stack Web Application

A modern full-stack web application built with **React**, **Next.js**, **Express**, and **Node.js**. 
This project serves as a scalable foundation for building robust web platforms with a focus on performance, maintainability, and developer experience.

## 🚀 Tech Stack

| Frontend | Backend | Database | Tools & Libraries |
|----------|---------|----------|-------------------|
| React.js | Node.js | MongoDB / PostgreSQL | Vite / Webpack |
| Next.js  | Express | Prisma / Mongoose | Axios, JWT, dotenv |
